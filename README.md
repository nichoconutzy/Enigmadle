# Enigmadle

Wordle but with an Enigma twist.
---
### Summary

This Game is a puzzle game inspired by both wordle and the enigma machine.
###
Players have 2 gamemodes:
* First is the 'Wordle' Gamemode inspired by wordle where Players find the 5 letter word of the day using the enigma machine.
* Second is the 'Sentence' Gamemode where players need to find a few letters from a sentence using the enigma machine.

### Getting Started
to run the program:

* run 'bash'
* python3 enigma_wordle_project/main.py
